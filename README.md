### Tipos de Commits Convencionales (Git Commit Types)

Los estándares de **Conventional Commits** permiten mantener un historial limpio, legible y automatizable en proyectos de desarrollo web.

| Icono / Emoji | Tipo de Commit | Descripción | Ejemplo de Uso |
| --- | --- | --- | --- |
| ✨ `:sparkles:` | **feat** | Una nueva característica o funcionalidad para el usuario | `feat: agregar sistema de autenticación JWT` |
| 🐛 `:bug:` | **fix** | Corrección de un error o bug en producción/desarrollo | `fix: corregir desbordamiento de texto en safari` |
| 📝 `:memo:` | **docs** | Cambios únicamente en la documentación (README, inline docs) | `docs: actualizar instrucciones de instalación` |
| 💄 `:lipstick:` | **style** | Cambios visuales o de formato (CSS, UI, indentación) | `style: adaptar navbar a diseño responsivo` |
| ♻️ `:recycle:` | **refactor** | Reorganización de código sin alterar su comportamiento externo | `refactor: optimizar función de filtrado de productos` |
| ⚡️ `:zap:` | **perf** | Mejoras en el rendimiento o tiempo de respuesta | `perf: lazy loading implementado para imágenes` |
| 🧪 `:test_tube:` | **test** | Añadir, corregir o actualizar pruebas unitarias o de integración | `test: agregar unit tests para la pasarela de pagos` |
| 🔧 `:wrench:` | **chore** | Tareas de mantenimiento, configuración de build o dependencias | `chore: actualizar paquetes de npm a últimas versiones` |
| 🎨 `:art:` | **format** | Mejores en la estructura/formato del código (ESLint, Prettier) | `format: aplicar reglas de linter en módulos` |
| 🚀 `:rocket:` | **deploy** | Implementaciones, scripts de CI/CD o lanzamientos | `deploy: configurar pipeline de Vercel para staging` |
